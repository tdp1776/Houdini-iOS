# Quick Start Commands

## initialize git
```bash
git init
```

## add files and first commit
```bash
git add .
git commit -m "Initial Houdini Phase 2 foundation"
```

## connect to GitHub
```bash
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/houdini-ios.git
git push -u origin main
```

## create dev branch
```bash
git checkout -b dev
git push -u origin dev
```

## normal daily save
```bash
git add .
git commit -m "Describe the work"
git push
```
