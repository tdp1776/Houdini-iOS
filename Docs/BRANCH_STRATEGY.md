# Branch Strategy

Recommended for Houdini:

## main
Use for:
- stable code
- known good builds
- version tags

## dev
Use for:
- active daily work
- combined feature progress

## optional feature branches
Use later if needed:
- feature/map-engine
- feature/voice
- feature/export-backup
- feature/monetization
- feature/testflight-prep

## recommendation
Start simple:
- use `main`
- use `dev`
- only add feature branches once the project gets busier
