# Houdini iOS

Houdini is a local-first iPhone app for writers.

It helps capture ideas, catalogue them intentionally, organize characters and chapters, support structured writing, and visualize relationships through maps.

## Core philosophy

- OTC by default
- Creative by invitation
- Cataloguing by command

## Current status

Early development.

## Planned core features

- local project database
- project selector
- OTC / Creative conversation modes
- strict command-based cataloguing
- character breakdowns
- chapter breakdowns
- content editor
- character relationship maps
- backup and export
- optional voice responses

## Tech stack

- Swift
- SwiftUI
- SwiftData

## Branches

- `main` for stable code
- `dev` for active development
